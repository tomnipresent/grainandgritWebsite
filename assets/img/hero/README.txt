HERO GALLERY IMAGES
===================
The hero gallery is built automatically from the numbered files in this
folder. Any file named  hero-1.jpg, hero-2.jpg, hero-3.jpg ...  becomes a
slide (and thumbnail), in NUMBER ORDER.

- REORDER  → just rename the files. hero-1 shows first, hero-2 second, etc.
- ADD more → drop in hero-6.jpg, hero-7.jpg ... the gallery + thumbnails
             resize to fit automatically. No code changes needed.
- REMOVE   → delete (or rename) a file and it drops out.

Accepted extensions: .jpg .jpeg .png .webp
Recommended: 16:9, matching dimensions across all files for a clean set.

Other images in this folder that are NOT named "hero-<number>" are ignored
by the gallery (e.g. old versions, alternates).
